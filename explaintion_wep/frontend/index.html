Day 01

Sprint 3 Planning & NLP Preprocessing

Building a task-aware Arabic text-cleaning pipeline that preserves sentiment-critical signals.

🎯 Sprint 3 Goal

Turn the Arabic sentiment classifier into a complete, rigorously evaluated and explained pipeline — from raw text through preprocessing, representation, model integration, error analysis, full evaluation, and SHAP explainability.

🔄 Preprocessing Pipeline

1 Normalization Strip diacritics, unify alef, remove tatweel
2 Tokenization NLTK word_tokenize on whitespace/punctuation
3 Number Removal Remove pure digit tokens
4 Latin Handling Lowercase embedded Latin tokens (brand names, titles)
5 Negation Protection Protect: لا لم لن ليس ما غير
6 Lemmatization Dictionary-based via qalsadi (train-freq ≥ 5)
7 Stop-word Removal NLTK Arabic function words (negators preserved)

⚖ Key Decisions

✅ Preserved

Negation words (لا, لم, ليس) are never removed by stop-word filtering. They flip sentiment meaning.

✅ Kept

Latin tokens (~3.9%) are lowercased but retained. They are content (brand names, artist names), not noise.

⚖ Separate

Two text pipelines maintained: classical preprocessing for TF-IDF (this work) vs. raw text for AraBERT transformer (Week 7).

Day 03

Computer Vision Preprocessing

OpenCV preprocessing engine for image classification tasks (dual-track curriculum).

Note: This is an NLP/text classification project. Day 3 implemented the CV preprocessing engine as part of the dual-track curriculum, but it was not applied to the sentiment classification pipeline. The engine is available for future CV tasks.

🖼 OpenCV Pipeline

1 Image Load cv2.imread() with IMREAD_COLOR
2 BGR → RGB cvtColor() color space conversion
3 Resize Target: 224×224, INTER_AREA downscale
4 Normalize MobileNet: (x/127.5) - 1.0 or Standard: x/255.0
5 Augment RandomFlip, RandomRotation, RandomZoom, RandomBrightness

⚠ BGR vs RGB Pitfall

OpenCV reads images in BGR order by default. Deep learning models expect RGB. Swapping channels causes catastrophic inference accuracy loss with no runtime error — the tensor shapes are identical.

🔍 SHAP Global Explainability

SHAP (SHapley Additive exPlanations) reveals which features contribute most strongly to predictions. For Logistic Regression + TF-IDF, SHAP values are exact.

✅

Genuine signals: Top features are domain-specific sentiment words, not artifacts.

⚠

Negation limitation: Negation tokens are features but their impact is inconsistent — TF-IDF cannot model scope.

💡

Error connection: Errors cluster around negation and mixed-sentiment examples where independent word features are insufficient.
